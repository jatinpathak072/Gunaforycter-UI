# Gunaforycter Restaurant Landing Page

A modern and elegant restaurant landing page built using **HTML5** and **CSS3**. The project features a dark-themed design, food menu cards, a chef's special showcase section, and a stylish footer, creating an attractive user experience for restaurant websites.

## 🚀 Features

* Modern dark-themed UI
* Food menu showcase cards
* Chef's Special section
* Elegant typography and layout
* Interactive hover effects
* Clean and organized code structure
* Built entirely with HTML and CSS

## 🛠️ Technologies Used

* HTML5
* CSS3
* Remix Icons

